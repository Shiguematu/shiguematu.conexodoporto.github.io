⚓ Conexo do Porto
Jogo educativo inspirado na mecânica de associação de palavras do jogo "Conexo" (Connections), adaptado para temas relacionados ao ambiente portuário, integridade, segurança, governança e cultura organizacional.

O objetivo do jogador é identificar corretamente quatro grupos de palavras relacionadas entre si, utilizando raciocínio lógico e conhecimento dos temas propostos.

Projeto Piloto
O Conexo do Porto é um projeto piloto desenvolvido como prova de conceito para demonstrar o potencial da gamificação em ações de treinamento, engajamento e disseminação de conhecimento organizacional.

Além do aspecto educacional, o projeto busca incentivar a cultura de inovação, experimentação e aprendizagem contínua, servindo como exemplo prático de iniciativa alinhada aos movimentos de:

Low Code
No Code
Citizen Development
Transformação Digital
A proposta é mostrar que soluções simples podem ser concebidas e implementadas rapidamente por profissionais de negócio, utilizando ferramentas acessíveis e apoio de Inteligência Artificial Generativa.

Citizen Development
Este projeto foi desenvolvido dentro da filosofia de Citizen Development, em que profissionais de negócio podem criar soluções digitais para resolver problemas ou apoiar iniciativas corporativas, mesmo sem atuarem formalmente como desenvolvedores de software.

A iniciativa demonstra como ferramentas modernas e Inteligência Artificial podem reduzir barreiras técnicas e acelerar a criação de protótipos funcionais de alta qualidade.
